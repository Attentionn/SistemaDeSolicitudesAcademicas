### Estructura básica de páginas

#### Layout Principal
- **Header**: Navegación principal con logo y menú
- **Sidebar**: Navegación secundaria (opcional)
- **Main Content**: Contenido principal de la página
- **Footer**: Información adicional y enlaces

#### Componentes Base
- **Cards**: Contenedores de información agrupada
- **Forms**: Formularios de entrada de datos
- **Tables**: Tablas de datos con paginación
- **Modals**: Ventanas emergentes para acciones específicas

### Distribución de elementos

#### Principios de distribución:
1. **Jerarquía visual**: Elementos más importantes en posiciones prominentes
2. **Agrupación lógica**: Funcionalidades relacionadas agrupadas
3. **Espaciado consistente**: Márgenes y padding uniformes
4. **Flujo de lectura**: De izquierda a derecha, de arriba a abajo

#### Colores
- **Primario**: #2563EB (Azul)
- **Secundario**: #64748B (Gris)
- **Éxito**: #10B981 (Verde)
- **Advertencia**: #F59E0B (Amarillo)

- **Títulos**: Inter, 24px, font-weight: 600
- **Subtítulos**: Inter, 18px, font-weight: 500

- **Captions**: Inter, 12px, font-weight: 400

- **Márgenes**: 16px, 24px, 32px, 48px
- **Padding**: 8px, 16px, 24px, 32px
- **Gaps**: 8px, 16px, 24px

### Interacciones básicas

#### Estados de componentes
- **Hover**: Cambio de color y cursor pointer
- **Active**: Estado presionado con feedback visual
- **Disabled**: Opacidad reducida y cursor not-allowed
- **Loading**: Spinner y estado de carga

#### Transiciones
- **Duración**: 200ms para micro-interacciones
- **Easing**: ease-in-out para transiciones suaves
- **Hover effects**: Transform scale(1.02) y shadow

## 3.4.4 Guía de estilo

### Paleta de colores

#### Colores primarios
- **Azul Principal**: #2563EB - Para elementos principales y CTAs
- **Azul Claro**: #3B82F6 - Para estados hover y variaciones
- **Azul Oscuro**: #1D4ED8 - Para estados active y pressed

#### Colores secundarios
- **Gris Claro**: #F8FAFC - Para fondos y backgrounds
- **Gris Medio**: #64748B - Para texto secundario
- **Gris Oscuro**: #0F172A - Para texto principal

#### Colores de estado
- **Éxito**: #10B981 - Para confirmaciones y estados positivos
- **Advertencia**: #F59E0B - Para alertas y estados de atención
- **Error**: #EF4444 - Para errores y estados negativos
- **Info**: #3B82F6 - Para información y estados informativos

### Tipografías

#### Jerarquía tipográfica
1. **H1 - Títulos principales**: 32px, font-weight: 700, line-height: 1.2
2. **H2 - Subtítulos**: 24px, font-weight: 600, line-height: 1.3
3. **H3 - Encabezados de sección**: 20px, font-weight: 600, line-height: 1.4
4. **Body - Texto principal**: 16px, font-weight: 400, line-height: 1.5
5. **Caption - Texto secundario**: 14px, font-weight: 400, line-height: 1.4
6. **Small - Texto pequeño**: 12px, font-weight: 400, line-height: 1.3

#### Aplicación de tipografías
```css
/* Títulos */
h1 { font-size: 2rem; font-weight: 700; color: var(--gray-900); }
h2 { font-size: 1.5rem; font-weight: 600; color: var(--gray-900); }
h3 { font-size: 1.25rem; font-weight: 600; color: var(--gray-900); }

/* Texto */
p { font-size: 1rem; font-weight: 400; color: var(--gray-700); line-height: 1.6; }
.caption { font-size: 0.875rem; color: var(--gray-500); }
```

### Iconografía

#### Sistema de iconos
- **Biblioteca**: Heroicons (Outline y Solid)
- **Estilo**: Outline para iconos regulares, Solid para estados activos
- **Tamaños**: 16px, 20px, 24px, 32px
- **Colores**: Heredan del color del texto o color específico

#### Iconos principales
- **Navegación**: Home, Users, Document, Settings
- **Acciones**: Plus, Edit, Delete, Check, X
- **Estados**: Success, Warning, Error, Info
- **Sistema**: Menu, Search, Filter, Sort

```css
/* Mobile First Approach */
/* xs: 0px - 575px (Mobile) */
/* sm: 576px - 767px (Tablet Portrait) */
/* md: 768px - 991px (Tablet Landscape) */
/* lg: 992px - 1199px (Desktop) */
/* xl: 1200px+ (Large Desktop) */

@media (min-width: 576px) { /* sm */ }
@media (min-width: 768px) { /* md */ }
@media (min-width: 992px) { /* lg */ }
@media (min-width: 1200px) { /* xl */ }
```

### Pruebas de usabilidad

#### Criterios de usabilidad
1. **Navegación intuitiva**: Máximo 3 clics para acceder a cualquier funcionalidad
2. **Carga rápida**: Tiempo de carga menor a 3 segundos
3. **Accesibilidad**: Compatible con lectores de pantalla
4. **Responsividad**: Funcional en todos los dispositivos
5. **Consistencia**: Patrones de diseño uniformes

#### Herramientas de testing
- **Lighthouse**: Para métricas de rendimiento y accesibilidad
- **Chrome DevTools**: Para testing responsivo
- **WAVE**: Para evaluación de accesibilidad
- **UserTesting**: Para pruebas con usuarios reales

#### Métricas de usabilidad
- **Task Success Rate**: >90% de tareas completadas exitosamente
- **Time on Task**: Tiempo promedio para completar tareas principales
- **Error Rate**: <5% de errores en tareas críticas
- **User Satisfaction**: Puntuación >4.0/5.0 en encuestas de satisfacción
